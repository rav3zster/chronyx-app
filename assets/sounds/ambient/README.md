# Ambient Sound Assets

Place the following MP3 files here for the Phase 3 ambient sound engine.
All files should be loopable (seamless loop points).

## Required files:
- rain.mp3        — Rain sounds
- cafe.mp3        — Café ambience
- white_noise.mp3 — White noise
- brown_noise.mp3 — Brown noise (deeper, warmer)
- forest.mp3      — Forest / birdsong
- ocean.mp3       — Ocean waves
- fireplace.mp3   — Crackling fireplace
- wind.mp3        — Gentle wind

## Recommended free sources:
- https://freesound.org (CC0 licensed sounds)
- https://mynoise.net (reference)
- https://pixabay.com/music/ (free license)

## Notes:
- Keep files under 3MB each (they loop, so short loops work great)
- Bitrate: 128kbps MP3 is sufficient
- Loop point: make sure the file ends where it began (seamless)
